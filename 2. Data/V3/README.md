# 第2讲 V3 学生材料

- `pbl-data-types-student-worksheet.docx`：学习目标、3W、小实验、课堂讲解。
- `pbl-data-types-reference.docx`：概念解释、字段字典、阅读路径与来源。
- `data/`：真实数据原样副本与明确标注的教学示例。
- `scripts/experiment_helper.py`：可选数值计算助手。使用课程已配置的 Python、pandas、numpy，从 V3 运行 `python scripts/experiment_helper.py`。Excel 自行计算同样可行。

学生只需收到两个 Word 文件、data 文件夹、计算助手；若配发原课件，保留 `../chap2_data.pptx` 的相对位置。核心概念与数据字典已包含在参考文件中。

学生须亲自运行或复核计算，并独立解释数据含义；计算助手不含解释答案。工作单中的表和简短建议直接用于汇报，无需再做一份报告或幻灯片。课后时间按计算环境已可用估计。

`review/` 是教师专用检查记录，含数值答案、模拟学生填答和页面渲染，**不要发给学生**。`scripts/build_v3.py`、`render_with_word.py`、`verify_sources.py` 是维护工具。

V2、原始课程数据及共享技能文件保持原样。本版内容范围以 `plan.docx` 第2讲及批准的 V3 计划为准。
